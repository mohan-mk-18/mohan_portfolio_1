# Mohan Kumar M: Portfolio

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Edit
Open the folder in VS Code and use the Live Server extension to preview `index.html`.
- Content: `index.html` (search for `TODO` to add live project links)
- Colors and fonts: top of `css/style.css` (the `:root` block)
- Resume: replace `assets/resume.pdf` and keep the same file name

## Deploy
**Vercel:** push to GitHub, then import the repo at vercel.com. Framework preset: Other. No build command.
**GitHub Pages:** push to GitHub, then Settings > Pages > Deploy from branch > `main` / root.
